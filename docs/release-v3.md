# DriveWeave v3.0.0

本轮重录五个 CARLA 交通场景，增加前后车、邻道车辆、对向车流与环内交通，并加入真实后视相机。车辆使用 CARLA 0.9.16 内置 Tesla Model 3，通过原生车辆物理与公开规则控制运行。

发布包含五条完整跟车视频、五条相机与处理四视图，以及一条综合视频。全部按原速 20 fps 播放，无新增画面文案；综合视频在场景和机位之间剪辑。前视、后视、图像处理及点云处理的独立视频也由公开编码脚本生成。

- 高速：八辆交通角色，慢车跟随、后车接近、约 6.9 秒安全间隙等待及实际换道。
- 匝道：保留完整合流、车道变换和驶出过程，按实际车辆速度与车身净距检查动态间隙。
- 左转：六辆对向车真实通过，主车让行后完成左转和驶出。
- 环岛：四辆环行车、两辆跟随车及另一入口车辆，主车让行、跟车绕行并驶出。
- 传感器：真实 RGB、实例真值区域、LiDAR 地面分离、降采样、几何聚类与标定投影。

源码、可移植场景计划和运行方法见仓库首页及 [交通录制说明](https://github.com/Ekko82/DriveWeave/blob/main/docs/traffic-v3.md)。原始采集、真实进程退出码、完整视频解码、源图一致性及人工抽样审阅分别记录于 [公开验收摘要](https://github.com/Ekko82/DriveWeave/blob/main/docs/media/accepted-v3-summary.json)。

环岛宽区域入口检查的一项原严格 FAIL 保留；独立的真实车道与车身扫掠冲突区域复核通过。左转等待全部对向车辆通过，不声称在车流中穿插；左转与环岛驶出尾段没有持续近距离后车。采样间距检查属于项目验收，不构成道路驾驶安全证明。

图像框采用仿真实例真值，点云采用几何处理；未运行训练后的驾驶或检测模型。本轮新场景为 CARLA 原生录制。综合片最后引用 v2 官方 CARLA/SUMO 协同源录像，其 SUMO GUI 为录制后同步回放。未运行 LimSim。
